# Lab 2 – NexusTech Solutions Security Policy Framework

**Course:** GRC102 – Information Security Governance
**Institution:** International Cybersecurity and Digital Forensics Academy (ICDFA)

## Scenario

NexusTech Solutions, a fast-growing cloud ERP provider (grown from 50 to 250 employees),
was relying on a single five-year-old "IT Rules" document that mixed policy, technical
instructions, and recommendations. As the newly appointed Information Security Manager,
the task was to build a structured, maintainable security policy framework aligned with
ISO/IEC 27001 and SOC 2.

## What this lab covered

- Separating security documentation into policies, standards, guidelines, and procedures
- Developing an Acceptable Use Policy
- Creating a User Access Request Procedure
- Preparing a Communication and Training Plan
- Writing a Policy Review and Maintenance Memo
