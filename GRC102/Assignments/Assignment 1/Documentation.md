# Assignment 1 – Principles of Information Security Governance

**Course:** GRC102 – Information Security Governance
**Institution:** International Cybersecurity and Digital Forensics Academy (ICDFA)

## Objective

A four-part assignment applying core information security governance principles to
real organizational scenarios.

## What this assignment covered

- Designing a governance structure for TechCorp
- Comparing COBIT and ISO/IEC 27001 as governance frameworks for MedSecure
- Analyzing the Equifax data breach through a governance lens
- Applying governance principles to GlobalFinance
