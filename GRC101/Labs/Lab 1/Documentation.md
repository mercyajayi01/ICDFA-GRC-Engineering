# Lab 1 – Linux Shell Navigation, File and Directory Management

**Course:** GRC101 – Introduction to Governance, Risk, and Compliance
**Institution:** International Cybersecurity and Digital Forensics Academy (ICDFA)

## Objective

Build practical Linux command-line skills needed for GRC and forensic work: navigating the
file system, managing files and directories, using permissions and `sudo`, searching with
`find` and `grep`, and organizing evidence in a structured folder layout.

## What this lab covered

- Setting up the Linux environment and confirming the working directory
- Creating a GRC-style folder structure (Governance, Risk, Compliance, Audit Evidence, Archive)
- Navigating between directories and listing contents, including hidden files
- Creating, viewing, copying, and moving files
- Searching for files and content using `find` and `grep`
- Checking disk information and file metadata
- Managing file permissions and using `sudo` for elevated actions
- Safely deleting files and verifying the change
- Editing files with `nano` and writing a README
- Archiving the final folder structure and producing a final directory tree

## Contents of this folder

- `GRC101_Lab1_Report.pdf` – the full submitted lab report

- `Evidence_Folder/` – the GRC-style folder structure created during the lab (Governance, Risk,
  Compliance, Audit Evidence, Archive), used as working evidence
